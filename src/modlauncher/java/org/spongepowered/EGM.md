# modlauncher: org.spongepowered

## Overview

This is a namespace directory for the shared ModLauncher integration. It holds only the `asm` package tree.

## Subdirectories & Boundaries

- asm: [./asm/EGM.md](./asm/EGM.md). The ModLauncher launch plugin, the base transformation service, the Forge agent, the root container and the `"ModLauncher"` Mixin service.
