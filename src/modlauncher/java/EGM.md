# modlauncher: java

## Overview

This is the Java source root of the `modlauncher` Gradle source set. It compiles against the `main` source set output (build.gradle line 130). The `modlauncher4` and `modlauncher9` source sets compile against this output (build.gradle lines 136 and 143).

## Subdirectories & Boundaries

- org: [./org/EGM.md](./org/EGM.md). The packages `org.spongepowered.asm.launch`, `launch.platform`, `launch.platform.container` and `service.modlauncher`.
