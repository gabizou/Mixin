# ap: java

## Overview

The Java source root of the `ap` source set. All of its code is in
`org.spongepowered.tools.obfuscation` and that package's subpackages.

## Subdirectories & Boundaries

- org: [./org/EGM.md](./org/EGM.md). Leads to the Mixin annotation
  processor:
  - The processors, the option keys, and the refmap and mapping-file outputs.
  - The obfuscation services (`mcp`, `fg3`), mirror type handles and
    validators.
