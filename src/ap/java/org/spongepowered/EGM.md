# ap: org/spongepowered

## Overview

Package grouping in the `ap` source set. It has no source files and contains
only `tools`.

## Subdirectories & Boundaries

- tools: [./tools/EGM.md](./tools/EGM.md). Leads to the Mixin annotation
  processor in `org.spongepowered.tools.obfuscation`, which generates refmaps
  and obfuscation mapping files at compile time.
