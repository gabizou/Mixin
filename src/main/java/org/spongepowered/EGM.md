# main: org.spongepowered

## Overview

This is a namespace directory in the `main` source set. Every core Mixin runtime package lives under `org.spongepowered.asm`.

## Subdirectories & Boundaries

- asm: [./asm/EGM.md](./asm/EGM.md). The Mixin runtime: the public consumer API (`mixin`), bootstrap and platform (`launch`), the service SPI (`service`), logging, obfuscation mappings, transformer interfaces and shared utilities.
