# transformer/meta

## Overview

This package holds four marker annotations. The transformer writes them into
emitted bytecode to record what it did to a class. Each one declares
`@Target({})`, so Java source cannot apply them. They appear only in
generated bytecode.

## Interface

- `@MixinInner`: `@Retention(CLASS)`. Attributes `String mixin()` and `String name()`, both with no default [MixinInner.java:MixinInner]
- `@MixinMerged`: `@Retention(RUNTIME)`. Attributes `String mixin()` and `int priority()`, both with no default [MixinMerged.java:MixinMerged]
- `@MixinProxy`: `@Retention(RUNTIME)`. Declares no attributes [MixinProxy.java:MixinProxy]
- `@MixinRenamed`: `@Retention(RUNTIME)`. Attributes `String originalName()` and `boolean isInterfaceMember()`, both with no default [MixinRenamed.java:MixinRenamed]

## Invariants

- `@MixinInner` has `CLASS` retention, so it is stored in the class file but invisible to `java.lang.reflect`. The other three have `RUNTIME` retention and are visible to reflection [MixinInner.java:MixinInner] [MixinMerged.java:MixinMerged]
- All four use `@Target({})`, so applying any of them in Java source is a compile error [MixinProxy.java:MixinProxy] [MixinRenamed.java:MixinRenamed]
- No attribute declares a default value [MixinMerged.java:priority] [MixinRenamed.java:isInterfaceMember]
- The emitted bytecode carries a `sessionId` value that the annotation types do not declare:
  - The `transformer` package writes `sessionId` into `@MixinMerged` and `@MixinProxy`.
  - `MixinApplicatorStandard.isAlreadyMerged` reads it back.
  - Reflection on these annotations will not expose `sessionId`.

  See `MixinTargetContext.methodMerged`, `MixinCoprocessorAccessor.process` and `MixinApplicatorStandard.isAlreadyMerged`, in the parent package src/main/java/org/spongepowered/asm/mixin/transformer.

## Side Effects

- None. These are annotation declarations only.
