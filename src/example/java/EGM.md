# example: java

## Overview

The Java source root of the `example` source set. Its only code is the sample
obfuscation service in the `org.spongepowered.tools.obfuscation.json` package.

## Subdirectories & Boundaries

- org: [./org/EGM.md](./org/EGM.md). Leads to `ObfuscationServiceJson`,
  `ObfuscationEnvironmentJson` and `MappingWriterJson`, which write mappings
  as JSON for the obfuscation type `json`.
